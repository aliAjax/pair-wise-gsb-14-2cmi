# 周边油站比价建议台

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Naive UI
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

区域调度员用的周边油站比价调价闭环，数据保存在浏览器 localStorage 中。

## 业务规则

1. **观察填写**：本站、油品、对方站、对方挂牌价、距离、采集人、采集时间，逐项校验。
2. **无效区**：采集时间超过 **24 小时**，或对方站距离超过 **3 公里**（或采集时间异常）的记录自动进入无效区，并写明具体无效原因；有效/无效状态随时间实时判定。
3. **生成向下建议**：同一本站 + 同一油品，需由**两名不同采集人**各自观察到低于当前挂牌价的价格，确认低价取两者更低者，才会生成建议。
4. **保底毛利底线**：建议价不得跌破「进货成本 + 保底毛利」。确认低价高于底线时生成待发布建议，可直接发布替换挂牌价。
5. **触底线待审批**：确认低价跌破底线时，建议价停在底线价并进入「触底线·待审批」区；审批人填写姓名与审批依据后才能按底线价发布，也可驳回（同样要写依据）。
6. **留痕**：已发布建议保留原价、发布价、发布/审批人、时间与依据；观察记录与建议永久关联，可在牌价板查看最近一次替换记录。依据过期（超过 24 小时）的未决建议会被锁定，需补采新价。
7. **底线可配置**：在「本站牌价与底线」中调整成本/保底毛利后，未决建议会重新判定是否触底线；挂牌价只能由发布动作替换。
