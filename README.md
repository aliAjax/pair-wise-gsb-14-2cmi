# 油品比价建议台

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Naive UI
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

区域调度员登记周边油站价格观察（本站、油品、对方站、对方挂牌价、距离、采集人、采集时间），页面自动完成比价闭环：

- 超过 24 小时或 3 公里的观察进入无效区并标注原因，不参与建议；
- 同一本站油品有两名不同采集人确认低价时，生成向下调价建议；
- 建议价跌破“成本 + 保底毛利”底线时停在待审批区，审批人写明依据后才能发布；
- 发布即替换挂牌价，原价与审批依据保留在已发布记录中。

数据默认保存在浏览器 localStorage 中，方便后续扩展接口、权限、图表或地图能力。
